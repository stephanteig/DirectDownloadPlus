# Direct Download Plus

En separat videreutvikling av DaVinci Resolve Workflow Integration Plugin Direct Download. Repositoryet starter som en komplett kopi av den installerte pluginen og skal beholde eksisterende Electron/JavaScript-UI, Resolve-integrasjon og arbeidsflyt.

Originalpluginen skal ikke endres:

`/Library/Application Support/Blackmagic Design/DaVinci Resolve/Workflow Integration Plugins/com.jhaimesfilmes.directdownload`

Se `docs/STRUCTURE.md`, `docs/ARCHITECTURE.md`, `docs/WEBDL-MAPPING.md` og `docs/TEST-PLAN.md` for baseline-kartlegging, WebDL-vurdering og planlagte verifikasjoner.
